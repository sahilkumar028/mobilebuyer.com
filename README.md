## 📱 About MobileBuyer.in

India's most trusted platform for buying and selling certified refurbished second-hand phones. We specialize in professional phone refurbishment with quality assurance and warranty coverage.

### ✨ Key Features

- **Multi-step Phone Selling Process**: Easy 4-step form to sell your old phone
- **Professional Refurbishment**: 32-point quality checks and genuine parts replacement
- **Quality Assurance**: Comprehensive warranty on all refurbished phones
- **Wide Brand Coverage**: Apple, Samsung, OnePlus, Xiaomi, Oppo, Vivo, and more
- **SEO Optimized**: Built with comprehensive SEO best practices
- **Mobile Responsive**: Perfect experience on all devices

### 🛠️ Technology Stack

- **Frontend**: React.js 18
- **Routing**: React Router DOM
- **SEO**: React Helmet Async
- **Styling**: Custom CSS with responsive design
- **Deployment**: GitHub Pages

### 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/mobilebuyer-in.git
   cd mobilebuyer-in
   ```

2. **Install dependencies**
   ```bash
   cd client
   npm install
   ```

3. **Start development server**
   ```bash
   npm start
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

### 📦 Deployment

#### GitHub Pages Deployment

1. **Update package.json homepage**
   ```json
   "homepage": "https://yourusername.github.io/mobilebuyer-in"
   ```

2. **Deploy to GitHub Pages**
   ```bash
   cd client
   npm run deploy
   ```

#### Alternative Deployment Options

- **Netlify**: Connect your GitHub repo for automatic deployments
- **Vercel**: Import your GitHub project for instant deployment
- **Heroku**: Deploy with buildpack for Node.js applications
