## Setup Instructions

1. **Create New Google Sheet**:
   - Go to Google Sheets
   - Create a new spreadsheet
   - Name it "MobileBuyer Phone Data"

2. **Create Phone_Data Sheet**:
   - Rename "Sheet1" to "Phone_Data"
   - Copy the above data into the sheet
   - Make sure Column A = Company, B = Model, C = Storage, D = Base_Price, E = Condition_Multiplier

3. **Create Sell_Phone_Leads Sheet**:
   - Add a new sheet named "Sell_Phone_Leads"
   - Add headers: Timestamp, Customer Name, Phone, Email, Company, Model, Storage, Phone Age (Months), Has Box, Has Charger, Physical Condition, Screen Condition, Battery Health, Estimated Value, Pickup Address

4. **Deploy Google Apps Script**:
   - Go to Extensions → Apps Script
   - Replace the default code with the DynamicCode.gs content
   - Save and deploy as web app
   - Copy the web app URL to your .env file

5. **Test the System**:
   - Visit your sell phone form
   - Companies should load dynamically
   - Models should appear when you select a company
   - Storage options should appear when you select a model

## Benefits of This System

✅ **Easy Management**: Update prices in Google Sheets without code changes
✅ **Dynamic Loading**: Form adapts to your available phone models
✅ **Accurate Pricing**: Backend calculates based on real data
✅ **No Price Display**: Users don't see estimates, you control pricing
✅ **Scalable**: Add unlimited brands, models, and storage options
